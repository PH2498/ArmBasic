# Proposal: 快速排序算法实现

## 变更概述
实现一个标准的快速排序（Quicksort）算法，支持对整数数组进行原地排序。

## 动机
快速排序是最经典的分治排序算法之一，平均时间复杂度 O(n log n)，是算法学习与面试中的高频考点。

## 范围
- 实现原地快速排序（in-place quicksort）
- 选择最右侧元素作为基准（pivot）
- 支持整数数组排序
- 包含分区函数（partition）
- 提供递归实现

## 非范围
- 不包含三路快排（3-way quicksort）
- 不包含迭代版本
- 不包含随机化 pivot 选择
- 不包含泛型/多类型支持

## 验收标准
- 正确排序空数组、单元素数组、正序数组、逆序数组、随机数组
- 包含重复元素的数组排序正确
- 原地排序，不创建额外数组副本
